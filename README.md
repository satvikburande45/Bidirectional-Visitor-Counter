# Bidirectional Visitor Counter Using IR Sensors

## Project Overview

This project focuses on developing a bidirectional visitor counter using two infrared (IR) sensors, IC 4093, IC 40110, and a seven-segment display. The circuit detects movement in opposite directions and updates the displayed count accordingly.

The project demonstrates the application of digital electronics, sensor interfacing, logic circuits, and digital counting systems.

## Objectives

- Detect movement using two IR sensors.
- Determine the direction of movement based on sensor activation.
- Increment or decrement the visitor count.
- Display the count on a seven-segment display.
- Understand the practical application of digital logic and electronic counters.

## Hardware Components

- Two IR sensors
- IC 4093
- IC 40110
- Seven-segment display
- Power supply
- Connecting wires
- Supporting electronic components

## Working Principle

The system uses two IR sensors positioned along the passage. When a person passes through the sensing area, the sensors activate in a particular sequence.

The control circuit interprets the sequence to determine the direction of movement and updates the counter accordingly.

- **Entry:** The count increases when the entry sequence is detected.
- **Exit:** The count decreases when the exit sequence is detected.
- **Display:** The current count is shown on the seven-segment display.

## Main Circuit Blocks

1. **Sensing Unit:** Detects movement using two IR sensors.
2. **Logic Unit:** Uses the associated electronic logic circuitry to process sensor signals.
3. **Counting Unit:** Updates the count according to the detected direction.
4. **Display Unit:** Shows the current count on a seven-segment display.
